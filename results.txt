### What is Artificial Intelligence?

**Definition:** 
**Artificial Intelligence (AI)** refers to computer systems or machines designed to simulate human intelligence. This means creating software that can learn from experience, recognize patterns, solve problems, and make decisions—tasks that traditionally required human thinking.

### How Does It Work in Simple Terms?
Normally, computers only do what humans explicitly program them to do step-by-step (e.g., *"If the user clicks this button, open that page"*). 

AI is different. Instead of writing rules for every single situation, engineers feed the computer massive amounts of data and give it algorithms (mathematical recipes). The computer analyzes this data, spots patterns, and teaches itself how to achieve a goal. The more data it gets, the better it becomes at its job.

---

### 3 Real-World Examples

#### 1. Content Recommendation Systems (e.g., Spotify, Netflix, TikTok)
* **What it does:** Predicts what song, video, or movie you want to see next based on your past behavior.
* **The AI behind it:** It uses **Machine Learning**. The system analyzes thousands of data points—what you watched, what you skipped, how long you stayed on a video, and what users with similar tastes liked—to build a personalized feed just for you.

#### 2. Large Language Models and Chatbots (e.g., ChatGPT)
* **What it does:** Understands questions written in plain English and generates human-like responses, essays, or code.
* **The AI behind it:** It uses **Natural Language Processing (NLP)**. The AI was trained on a vast library of internet text, learning the statistical relationships between words. When you type a prompt, it predicts the most logical and helpful words to respond with, almost like super-advanced auto-complete.

#### 3. Navigation and Route Optimization (e.g., Google Maps)
* **What it does:** Calculates the fastest way to get to your destination and updates the route in real-time.
* **The AI behind it:** It processes real-time data from millions of smartphones on the road. The AI analyzes historical traffic patterns alongside current conditions (like construction, weather, or accidents) to predict traffic flow and dynamically suggest the quickest detour.

---

### Key Takeaway
AI is not a conscious robot with feelings; it is essentially **advanced statistics and pattern recognition at scale**, allowing machines to perform complex tasks that mimic human reasoning.

PROMPT:
Write a Python function that checks whether a number
is prime. Include clear comments and 3 example test cases.
Explain how the function works briefly.

MODEL RESPONSE:
Here is the Python function along with comments, test cases, and a brief explanation.

### Python Code

```python
def is_prime(n: int) -> bool:
    """Checks if a given integer n is a prime number.

    Returns True if prime, False otherwise.
    """
    # Numbers less than or equal to 1 are not prime
    if n <= 1:
        return False

    # 2 is the smallest and only even prime number
    if n == 2:
        return True

    # Exclude all other even numbers immediately
    if n % 2 == 0:
        return False

    # Check for odd factors up to the square root of n.
    # We step by 2 to skip even numbers.
    limit = int(n**0.5) + 1
    for i in range(3, limit, 2):
        if n % i == 0:
            return False  # Found a divisor, so it's not prime

    return True  # No divisors found, so it is prime


# --- 3 Example Test Cases ---

# Test Case 1: A standard prime number
print(f"Is 29 prime? {is_prime(29)}")  # Expected: True

# Test Case 2: A composite (non-prime) number
print(f"Is 15 prime? {is_prime(15)}")  # Expected: False

# Test Case 3: An edge case (1 is not prime)
print(f"Is 1 prime?  {is_prime(1)}")  # Expected: False
```

---

### How It Works

1. **Edge Case Elimination**: 
   - Any number $\le 1$ is immediately returned as `False` because primes must be greater than 1.
   - The number `2` is returned as `True` (it is the only even prime).
   - Any other even number is ruled out using `n % 2 == 0`.

2. **Square Root Optimization ($\sqrt{n}$)**:
   - If a number $n$ has a factor larger than $\sqrt{n}$, it must have a matching factor smaller than $\sqrt{n}$. Therefore, the loop only needs to check numbers up to $\lfloor\sqrt{n}\rfloor$, drastically reducing execution time for large numbers.

3. **Odd Steps**:
   - Since even numbers are already ruled out, the loop starts at `3` and increments by `2` (`range(3, limit, 2)`), testing only odd potential factors. If none evenly divide $n$, the number is prime.

### What is a Python List?

Think of a **list** just like a real-life list you might write on a piece of paper—like a grocery list, a to-do list, or a playlist of your favorite songs. 

In Python, a list is simply a way to store a collection of items together in a single place. We make a list by putting our items inside **square brackets `[]`**, separated by commas.

---

### Code Example

Here is a quick example of how you can create and use a list in Python:

```python
# Creating a list of snacks for a study session
snacks = ["chips", "apple", "chocolate"]

# Python counts starting at 0, so snacks[0] gives the first item
print(snacks[0])  # Output: chips

# We can easily add a new snack to our list
snacks.append("popcorn")

print(snacks)  # Output: ['chips', 'apple', 'chocolate', 'popcorn']
```

---

### 3 Key Points to Remember

1. **They have a specific order (Indexing):** Python remembers the order in which you put things into a list. Just remember the fun quirk: **Python starts counting at `0`**, so the very first item is always at index `0`.
2. **They are changeable (Mutable):** You can update a list anytime! You can add new items, take items out, or swap an old item for a new one without having to start over.
3. **They can hold anything:** A list can hold words (strings), numbers (integers), or even a mix of both all inside the same bracket!
