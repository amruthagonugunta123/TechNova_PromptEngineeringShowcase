# Prompt Engineering Showcase

## Project Overview
The Prompt Engineering Showcase is a Python-based Generative AI project that demonstrates how different prompts can be used to obtain useful responses from a Large Language Model (LLM). It uses the Gemini API to generate responses for different real-world and educational use cases.

## Objectives
- Demonstrate different prompt engineering techniques.
- Design 10 prompts for different use cases.
- Explore zero-shot, few-shot, and reasoning-style prompting.
- Compare outputs produced by different prompting styles.
- Save generated responses for review and documentation.

## Technologies Used
- Python
- Google Gemini API
- `google-genai` Python SDK
- VS Code

## Features
1. Zero-Shot Prompting
2. Few-Shot Prompting
3. Reasoning-Style Prompting
4. Text Summarization
5. Translation
6. Text Classification
7. Creative Writing
8. Code Generation
9. Structured Output
10. Role-Based Prompting
11. Zero-Shot vs Few-Shot Comparison

## Installation and Setup

1. Install Python.
2. Install the Gemini SDK:

   ```bash
   python -m pip install google-genai
   ```

3. Create a Gemini API key through Google AI Studio.
4. Set the API key as an environment variable. Do not hard-code it in the source code.

   **Windows PowerShell:**

   ```powershell
   $env:GEMINI_API_KEY="YOUR_API_KEY"
   ```

5. Run the application:

   ```bash
   python main.py
   ```

6. Choose an option from the menu to run a prompt experiment.

## Output
The application displays the generated response in the terminal and saves successful prompt experiments to `results.txt`.

## Prompting Techniques

- **Zero-shot prompting:** Gives the model a task without examples.
- **Few-shot prompting:** Provides examples to guide the model's response.
- **Reasoning-style prompting:** Asks the model to solve a problem carefully and present calculation steps or a concise explanation.

## Conclusion
This project demonstrates how prompt structure and examples can influence the responses generated by an LLM. It provides a simple interactive environment to experiment with prompting techniques and review their outputs.
